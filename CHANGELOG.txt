OStim Beast Form changelog - That Guy (Coronerra)
From 1.0.1 this repository (Coronerra/OStim-Beast-Form) is the main one again; Merged, TWO Edition, TWO Patch and TWO Herm Patch are superseded.
Release 1.0.2 also carries: WVL 0.3.1 Patch 0.2 (animation patch for Werewolf and Vampire Lord OStim 0.3.1), Softbody / Tullius Patches 1.0.2 (readme only), Herm / Futa Patch 1.0.1 (unchanged), Ostrands with Werewolves 0.8.0.3.

  were ignored. 1.0 / 1.0.1 pointed the female werewolf body at this
  mod's converted softbody body for core B (TWO) and the Growl + TWO

    "Yes, softbody" in 0.8.x and as 1.0 / 1.0.1.
- Only the body and cock paths in OStim_Beast_Form_TWO.esp (core B) and

- Docs: source link now https://github.com/Coronerra/OStim-Beast-Form,
  BodySlide notes updated.

OStim Beast Form 1.0.1
- Own log file for troubleshooting: Data\SKSE\Plugins\OStimBeastForm.log
  (MO2: overwrite). Header and startup block every game load (version,
  core, mods found, race checks, OCR keywords, scene registrations, MCM
  settings), then beast scenes / beast couple scenes, start-key failures,
  timer pause / resume, climaxes and loads, Beast Pie, aroused-body
  swaps, Beast Aware form changes. Lines still go to Papyrus.0.log.
- MCM: "Write log file" (ON by default). Restarts after 10 game loads,
  at most 2000 lines per load. PapyrusUtil soft check: without it,
  nothing is written.
- Scripts and docs only. Plugins, FormIDs, meshes and textures unchanged.
  No animation pack is touched.

OStim Beast Form 1.0 (box build, not released)
- New installer: three cores (A vanilla / B TWO / C Growl), an OCreatures
  Reforged question, optional Beast couples, optional Growl + TWO add-on.
- Core A (new): no TWO plugin needed. Same plugin name and FormIDs as the
  TWO core; its own head-part records (TWO-style heads you copy in).
- Growl core: werebears (OStim actor properties, MCM "Werebears use
  werewolf scenes", aroused werebear skin without OCR).
- No animation pack is edited any more: Lirael role swaps, her menu edits
  and the OCreatures scene overrides are gone. The OCR stand-in start
  poses install only when OCreatures Reforged isn't installed.
- Converted female body and cock for everyone (one plugin per core, no
  softbody variants). The OCum script moved to the Softbody / Tullius
  download, the herm patch to its own download.
- Big loads: werewolves and werebears only (MCM label updated).
- Hotkey works in werebear form.
- SkyrimNet: one shared pack for every core, simpler Vampire Lord line,
  werebear partner note.
- BFA head morph files ship in this mod's own folders.
