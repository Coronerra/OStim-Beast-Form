OStim Beast Form 1.0.1
- Own log file for troubleshooting: Data\SKSE\Plugins\OStimBeastForm.log
  (MO2: overwrite). Header and startup block every game load (version,
  core, mods found, race checks, OCR keywords, scene registrations, MCM
  settings), then beast scenes / beast couple scenes, start-key failures,
  timer pause / resume, climaxes and loads, Beast Pie, aroused-body
  swaps, Beast Aware form changes. Lines still go to Papyrus.0.log.
- MCM: "Write log file" (ON by default). Restarts after 10 game loads,
  at most 2000 lines per load. PapyrusUtil soft check: without it,
  nothing is written.
- Scripts and docs only. Plugins, FormIDs, meshes and textures unchanged.
  No animation pack is touched.
